Enter your lender details

This service is for lenders to file charge (mortgage) documents.

If you're a lender and do not have the authentication codes needed to sign in, you'll have to apply to register as a lender to file charge documents for a company (opens in new tab).


Help with company number
This is 8 characters long. You can find it by searching for the company on the Companies House register (opens in new tab).
Help with authentication codes

A lender authentication code is an 8 character code. It's required if you need to file charge (mortgage) documents online for other companies.

A presenter authentication code is an 11 character code. It identifies the agent or software user who is submitting a filing.

If you've previously registered as a lender but no longer have the codes, contact us at enquiries@companieshouse.gov.uk
